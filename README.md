# Ella 48-DIG Reagent Prep Wizard

Offline helper for preparing reagents for the Simple Plex Ella 48-Digoxigenin open cartridge workflow.

Open `index.html` in a browser to use it. The wizard includes:

- Step-by-step checklists from the quick start guide
- DIG and biotin reaction volume helpers
- Optional non-antibody molar-excess calculator
- Spin-column recommendation by molecular weight
- A280 concentration and Reagent Diluent 2 calculations
- Separate capture and detect antibody dilution calculators
- Cartridge loading totals and a copyable run summary

This is a workflow aid only. Follow your lab SOP, safety requirements, and the current manufacturer documentation.
