● Before you analyse

Check these in Quantist

  • This is an unofficial conversion tool. Verify converted results before reporting them.
  • Total Events is the sum of the per-region bead counts, not a true event count.
  • Control ranges are set to ±30% of expected. Edit them in Quantist if your QC limits differ.
  • Bio-Plex curve-fit coefficients are not carried over. Quantist refits each curve.
  • Wells are numbered column-wise (A1, B1 … H1, A2 …) because the export does not record read order.
  • The first time you use a new export, compare one or two standard curves and QC recoveries with Bio-Plex Manager.
